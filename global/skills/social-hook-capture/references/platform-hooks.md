# Platform Hook Notes

## Reddit

Reddit rewards context, honesty, and community fit. Avoid generic marketing copy. For a named subreddit, verify current rules before final posting.

Good Reddit shapes:

- "I built X because Y kept bothering me."
- "This tiny mechanic changed how the game feels."
- "Before/after: I optimized X and got Y result."
- "I need feedback on X, not on the whole game."
- "I ported a browser Three.js game toward Steam; here is the weird part."

Avoid:

- empty hype,
- "Would you play this?" as the whole idea,
- broad self-promo with no useful detail,
- reposting the same screenshot/caption pattern.

## X / Twitter

Use one sharp visual and one compact claim. Keep the first sentence short. Add a thread only if there are concrete steps or before/after proof.

## LinkedIn

Frame as a build note, technical decision, milestone, or lesson learned. Keep the tone practical.

## Discord / Community

Use direct update language. Mention what changed, why it matters, and what feedback is useful.

## Hook Selection

Prefer hooks with proof:

- visual novelty,
- measurable improvement,
- surprising constraint,
- player-facing feature,
- technical transformation,
- clear before/after,
- useful lesson.

Choose one hook per post. If there are multiple, make variants in the same markdown file instead of mixing angles.

## Draft QA

- The target audience is named.
- The first line can stand alone.
- The screenshot proves or supports the claim.
- If motion is the point, the GIF shows the payoff within the first second.
- The post does not overclaim.
- The copy differs from prior posts.
- The call for feedback is specific.
